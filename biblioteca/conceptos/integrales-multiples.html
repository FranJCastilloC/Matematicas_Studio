Integrales múltiples: el volumen se suma por columnas

La integral de una variable suma rectángulos para medir un área. La integral doble hace lo mismo un piso más arriba: parte el suelo en baldosas, levanta sobre cada una una columna tan alta como la función y suma los volúmenes. Cuando las baldosas se achican, la suma se queda quieta en un número: ese número es la integral. Con la misma idea vas a calcular el área de la campana de Gauss y probabilidades de dos variables.

Antes de empezar, piénsalo tú. Tienes un techo curvo sobre un terreno cuadrado y sabes la altura del techo en cada punto. ¿Cómo calcularías cuánto espacio hay debajo? Escríbelo como te salga, aunque esté mal.

¿Y si el techo baja del suelo?

Si toma valores negativos, las columnas cuelgan hacia abajo y restan. La integral doble mide un volumen con signo: lo que está arriba menos lo que está abajo. Puede dar cero aunque haya mucho volumen. Es lo mismo que pasa con el área bajo una curva que cruza el eje. El reto de ojo clínico de abajo juega con esto.

      La versión sin bucles, y una región que no es rectángulo
      

        
Con NumPy la malla de puntos medios se arma de una vez y se suma con una sola operación. Con 300 × 300 celdas:

        
import numpy as np
m = n = 300
xm = (np.arange(m) + 0.5) * 3 / m
ym = (np.arange(n) + 0.5) * 3 / n
X, Y = np.meshgrid(xm, ym)
print((X**2 + Y**2).sum() * (3 / m) * (3 / n))
# 53.999849999999995

        
En R, outer arma la misma tabla de valores:

        
xm <- ((1:300) - 0.5) * 3 / 300
print(sum(outer(xm, xm, function(x, y) x^2 + y^2)) * (3 / 300)^2, digits = 10)
# [1] 53.99985

        
Para el triángulo del paso 5, dblquad acepta límites de adentro que dependen de x, como funciones:

        
tri, err = integrate.dblquad(lambda y, x: x**2 + y**2, 0, 3, 0, lambda x: x)
print(round(tri, 6))
# 27.0

        
Y en R el límite de arriba de la integral de adentro pasa a ser x:

        
f <- function(x, y) x^2 + y^2
rebanada <- function(x) integrate(function(y) f(x, y), 0, x)$value
print(integrate(Vectorize(rebanada), 0, 3)$value)
# [1] 27
