LSTM y GRU

En la página de RNN viste que la señal que vuelve hacia atrás se encoge en cada paso, hasta que la red no puede aprender a usar algo que leyó hace diez letras. La LSTM le agrega a la celda una cinta transportadora, el estado de celda, y tres compuertas que funcionan como grifos: una decide cuánto se conserva, otra cuánto se escribe y otra cuánto se muestra. Aquí vas a ver una celda de juguete, con todos sus pesos escritos a mano, guardar la primera letra de una palabra durante diez pasos. Al final, la GRU hace lo mismo con dos grifos.

Antes de empezar, piénsalo tú. Tienes que recordar un número de teléfono mientras alguien te dicta una lista de compras larga. ¿Qué haces con cada cosa nueva que escuchas para no perder el número? Si construyeras esa memoria con números, ¿qué decisiones tendría que tomar en cada momento?

Paso 1

Recordar la primera letra

Con las mismas letras de la página de RNN, h, o, l, a, hay una tarea nueva. La palabra empieza con h o con o, después vienen muchas l, y al final llega una a, que funciona como pregunta: ¿con qué letra empezó? En hllllllllla la respuesta es h, y lo que hay que recordar está diez letras atrás.

Una memoria que resuelva esto tiene que hacer cosas distintas según la letra que llega. Antes de mirar el escenario, decide qué tiene que hacer mientras llegan las l.

La UD4 presenta la LSTM justamente así: una variante de la RNN con una célula de memoria gestionada por puertas .

Predice antes de mirar

En el escenario, la franja horizontal es la cinta: la memoria. Debajo de cada letra hay tres barras, los grifos: olvido, entrada y salida. Barra llena es grifo abierto (cerca de 1); vacía, cerrado (cerca de 0). Con la h se abre la entrada y la cinta se llena de verde azulado. Durante las l, la entrada está cerrada y el olvido abierto: la cinta conserva y se desgasta apenas. Con la a se abre la salida y la celda muestra lo que guardó.

Ojo con el nombre: el grifo de olvido abierto quiere decir que la celda conserva. Es el nombre que usa todo el mundo (forget gate), y confunde a todos al principio. Piénsalo como "grifo de lo que se queda".

Mira la fila de arriba del escenario: mientras pasan las l, vale alrededor de 0.01. Antes de seguir, decide qué quiere decir eso.

Decide antes de seguir

No olvidó. La memoria está en la cinta, que durante las l va de 0.92 a 0.69; es lo que la celda muestra, y el grifo de salida está casi cerrado. Esa es la diferencia con la RNN: allí el estado que se guarda y el que se muestra son el mismo vector. En la LSTM hay dos, de largo plazo y de corto plazo: de ahí el nombre, long short-term memory, una memoria de corto plazo que dura mucho.

Paso 7

La GRU: dos grifos y sin cinta aparte

La GRU (Cho y otros, 2014) simplifica la celda. Junta olvido y entrada en un solo grifo, el de actualización : lo que se conserva es y lo que entra es , así que suman 1. No tiene cinta aparte: hace de cinta y de salida a la vez. Y el grifo de reinicio decide cuánto del estado anterior mira el candidato.

En el escenario, cambia entre LSTM y GRU con la misma palabra. La GRU de juguete usa los mismos números: tiene los pesos del grifo de entrada (se abre con h y o), el reinicio se cierra con h y o (al empezar una palabra no hace falta mirar el pasado) y el candidato es el de la LSTM. Ninguno de los dos materiales escribe estas ecuaciones: la UD4 describe la GRU en prosa , las diapositivas la dibujan con , y un nodo "1−" , y Raschka solo le dedica el recuadro de la página 512. Estas son las de Chung y otros (2014).

Un aviso sobre la UD4: dice que la puerta de reinicio "determina cuánto de la memoria pasada se olvida". No es así: el reinicio solo decide cuánto de entra al candidato. Quien mezcla memoria vieja y nueva es la de actualización. Y otro sobre las librerías: PyTorch y Keras usan la convención contraria, con multiplicando al estado viejo. Lo vas a ver en la vida real.

      La señal hacia atrás por la cinta, contra diferencias finitas (se corrió en Python y R)
      

        
¿Cuánto cambia la respuesta final  si empujas un poquito la cinta después de la primera letra? Solo por la cinta, la cuenta es , con . El programa la compara con la derivada medida empujando  hacia arriba y hacia abajo. Python:

        
import numpy as np

letras = ["h", "o", "l", "a"]
W = {"i": [0, 4, 4, -4, -4], "f": [0, 0, 0, 0, 0], "g": [1, 2, -2, -1, 0], "o": [0, -4, -4, -4, 4]}
b = {"i": 0, "f": 4, "g": 0, "o": 0}
sigmoide = lambda z: 1 / (1 + np.exp(-z))

def correr(palabra, empuje=0.0):              # empuje: lo que se le suma a c_1
    h, celda, fs = 0.0, 0.0, []
    for t, letra in enumerate(palabra):
        v = np.concatenate(([h], np.eye(4)[letras.index(letra)]))
        i, f, o = (sigmoide(np.dot(W[k], v) + b[k]) for k in ["i", "f", "o"])
        g = np.tanh(np.dot(W["g"], v) + b["g"])
        celda = f * celda + i * g + (empuje if t == 0 else 0)
        h = o * np.tanh(celda)
        fs.append(f)
    return h, celda, o, fs

palabra = "hllllllllla"
h, celda, o, fs = correr(palabra)
cinta = np.prod(fs[1:])                        # cruzar la cinta de c_1 a c_11
print("producto de las f:", f"{cinta:.4f}")
print("solo por la cinta:", f"{o * (1 - np.tanh(celda) ** 2) * cinta:.4f}")
eps = 1e-6
num = (correr(palabra, eps)[0] - correr(palabra, -eps)[0]) / (2 * eps)
print("diferencias finitas:", f"{num:.4f}")

letras <- c("h", "o", "l", "a")
W <- list(i = c(0, 4, 4, -4, -4), f = c(0, 0, 0, 0, 0), g = c(1, 2, -2, -1, 0), o = c(0, -4, -4, -4, 4))
b <- list(i = 0, f = 4, g = 0, o = 0)
sigmoide <- function(z) 1 / (1 + exp(-z))

correr <- function(palabra, empuje = 0) {      # empuje: lo que se le suma a c_1
  h <- 0; celda <- 0; fs <- c()
  for (t in seq_along(palabra)) {
    v <- c(h, diag(4)[match(palabra[t], letras), ])
    i <- sigmoide(sum(W$i * v) + b$i); f <- sigmoide(sum(W$f * v) + b$f); o <- sigmoide(sum(W$o * v) + b$o)
    g <- tanh(sum(W$g * v) + b$g)
    celda <- f * celda + i * g + (if (t == 1) empuje else 0)
    h <- o * tanh(celda)
    fs <- c(fs, f)
  }
  list(h = h, celda = celda, o = o, fs = fs)
}

palabra <- strsplit("hllllllllla", "")[[1]]
r <- correr(palabra)
cinta <- prod(r$fs[-1])                        # cruzar la cinta de c_1 a c_11
cat("producto de las f:", sprintf("%.4f", cinta), "\n")
cat("solo por la cinta:", sprintf("%.4f", r$o * (1 - tanh(r$celda)^2) * cinta), "\n")
eps <- 1e-6
num <- (correr(palabra, eps)$h - correr(palabra, -eps)$h) / (2 * eps)
cat("diferencias finitas:", sprintf("%.4f", num), "\n")
