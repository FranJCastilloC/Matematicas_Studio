## Fórmulas y código clave

No hay fórmulas matemáticas en A, B ni C. La única ecuación de B es el ejemplo de sintaxis $h^2 = c_1^2+c_2^2$ en `#formato-del-texto`.
Si una página necesita la fórmula de Pearson o la de Spearman, hay que citarla de otro libro (OpenStax Stats u OpenIntro, ya mapeados).
Código de R más útil para una página de la biblioteca (todo verificado arriba):
- `cor(x, y, method = "pearson" | "spearman", use = "complete.obs")` (B `#correlación-en-r`; A p.12 para `use`).
- `hist(x, breaks = 25)`, `plot(density(x, bw = ..., kernel = "epanechnikov"))`, `boxplot(y ~ g, data = ...)` (A p.13-16).
- `table()`, `prop.table(table(...), margin = 1 | 2)` (A p.11, 20).
- `table1(~ ... | grupo, data, render.continuous = ..., na.is.category = FALSE)`, `tbl_summary(by = ...) |> add_p()` (B).
- `naniar::vis_miss()`, `miss_var_summary()` (B); `inspectdf::inspect_na()` (A p.28).
- `GGally::ggpairs(df, columns = ..., mapping = aes(color = ...))` (A p.33-35, B).
